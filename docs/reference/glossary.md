# Glossary

**Active sensor**

The sensor session that xDrip4iOS currently associates with incoming readings.

**AID Type**

The automated insulin delivery system associated with Nightscout data. Selecting the correct type allows xDrip4iOS to interpret compatible pump and Looping information.

**AGP**

Ambulatory Glucose Profile. A 24-hour chart that combines readings from several days to show the usual glucose pattern and its variation.

**Backfill**

Older readings retrieved after a connection gap.

**Bluetooth channel**

One of the Bluetooth connections made available by a Dexcom G6 transmitter. xDrip4iOS normally uses the Mobile App channel. The other channels are intended for specific multi-device setups.

**Calibration**

A relationship between sensor data and a reference blood glucose measurement. Not every system accepts or needs user calibration.

**CGM**

Continuous glucose monitoring system.

**Coexistence Mode**

A Dexcom G6 and ONE connection mode that allows xDrip4iOS to receive readings while another app, such as the Dexcom app or CamAPS, controls the transmitter connection.

**CV**

Coefficient of variation. A percentage that describes how much glucose readings vary in relation to the average.

**Data Capture**

The percentage of expected CGM readings that are available for a selected period.

**Delta**

The change from a recent glucose reading to the current reading.

**Follower**

An xDrip4iOS mode that downloads readings from an online source.

**GMI**

Glucose Management Indicator. An estimated HbA1c value calculated from average CGM glucose. It is not a laboratory HbA1c result.

**Heartbeat device**

A Bluetooth device that can help Follower mode check for readings in the background. It does not supply glucose readings.

**Master**

An xDrip4iOS mode that receives readings from locally configured CGM hardware.

**Nightscout**

A separately hosted web application that can receive, display, and provide diabetes data.

**Raw value**

The value read from the sensor before xDrip4iOS applies calibration or other adjustments.

**Sensor session**

The period between a sensor start and sensor stop. A running session can often be added to xDrip4iOS without starting it again.

**Shared Calendar**

A follower source that receives glucose readings from calendar events created by Calendar Share on another device.

**Time in Range**

The percentage of readings within a defined glucose range. Statistics and reports use standard clinical ranges that can differ from the personal ranges used on Home.

**Time in Tight Range**

The percentage of readings from 70 to 140 mg/dL, or 3.9 to 7.8 mmol/L.

**Transmitter**

A reusable or integrated electronic device that sends sensor data by Bluetooth.

**Trend**

An indication of the direction and rate of glucose change.
