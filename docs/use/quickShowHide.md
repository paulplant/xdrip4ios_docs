# Quick Show/Hide

Select **Quick Show/Hide** in the toolbar at the top of **Home** to change common display options without opening Settings.

## Glucose Chart

- **Show Original Glucose Readings** compares stored original values with adjusted values when Glucose Adjustments are active.
- **Show Treatments** shows or hides treatment markers on the chart.
- **Show Sensor Noise** shows or hides the sensor noise bands.
- **Main Chart Hours** selects a 3, 5, 8, 12, or 24-hour chart range.

## Home Screen

- **Show Mini Chart** shows or hides the longer history chart below the main chart.
- **Show Statistics** shows or hides the compact statistics on **Home**.

## Additional Items

- **Speak Readings** enables or disables spoken glucose readings.
- **Large Snooze Screen** uses a larger snooze picker when an active alarm opens the screen automatically.

These are the same saved choices used by the related Settings screens. A change made here remains active after Quick Show/Hide is closed.

Changing **Main Chart Hours** also changes the chart range in **Settings > Glucose Display > Home Screen**. Pinching the chart changes the same setting.

The list depends on the current data source and enabled features. These choices change what xDrip4iOS displays. They do not delete stored readings or treatments.
