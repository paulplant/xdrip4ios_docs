# Quick Show/Hide

Select **Quick Show/Hide** in the toolbar at the top of **Home** to change common display options without opening Settings.

## Chart

- **Time Range** selects a 3, 5, 8, 12, or 24-hour chart range.
- **Chart Rotation** allows the landscape chart when the iPhone is rotated.
- **Therapy** shows or hides treatments, basal data, IOB, COB, pump information, and AID status on Home and the landscape chart.
- **Sensor Noise** shows or hides the sensor noise bands.

## Glucose Display

- **Live Activity** enables or disables the saved Live Activity style. It is shown in Master mode and in Follower mode when Heartbeat keep-alive is available.
- **Speak Glucose** enables or disables spoken glucose readings.
- **Large Snooze Screen** uses a larger snooze picker when an active alarm opens the screen automatically.

These are the same saved choices used by the related Settings screens. A change made here remains active after Quick Show/Hide is closed.

Changing **Time Range** also changes the chart range in **Settings > General > Home Screen**. Pinching the chart changes the same setting.

The list depends on the current data source and enabled features. These choices change what xDrip4iOS displays. They do not delete stored readings or treatments.
