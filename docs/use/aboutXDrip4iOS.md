# About xDrip4iOS

The **About xDrip4iOS** section shows information about the installed app.

It includes the app version, build information, installation date, licence information, and the GitHub project link.

The version identifies the public app release. The build number identifies the exact compiled build and is also needed when two installations show the same version name.

Select the GitHub project link to open the source repository. Licence information describes the open-source terms used by the app and its included components.

Include the version and build when reporting a problem. Do not include account details, passwords, tokens, or personal health information in a public report.
