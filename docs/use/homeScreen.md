# Home Screen

Open **Settings > General > Home Screen** to configure the main chart and other Home options.

## Home Layout

**Therapy Summary** shows or hides the pump panel and the therapy status area on Home. It is available when **Therapy** is enabled.

**Mini-Chart** shows or hides the longer history chart below the main chart. The range is selected directly from the mini-chart.

**Statistics** shows or hides the compact statistics on Home.

**Sensor Lifetime** selects **Elapsed** or **Remaining**. The same choice is used by the Apple Watch app. This changes the display only. It does not extend or stop the sensor.

## Chart

**Time Range** selects a 3, 5, 8, 12, or 24-hour range. The same control is available under **Quick Show/Hide > Chart**. Pinching the chart changes the same saved range.

**Chart Rotation** allows the landscape chart when the iPhone is rotated.

**Original Values** displays the original glucose values when [Glucose Adjustments](glucoseAdjustments.md) are active.

**Sensor Noise** adds shaded noise bands when this information is available. The bands show how stable the sensor signal was. They do not show glucose accuracy.

## Therapy

**Therapy** is the main display switch for treatments, basal data, IOB, COB, pump information, and AID status on Home and the landscape chart. It does not delete treatments or stop IOB and COB calculations.

**IOB/COB Curves** shows available insulin on board and carbohydrates on board curves. The values can come from a connected AID source or can be estimated from recorded treatments. This setting is available when **Therapy** is enabled.

**Basal Position** selects **Top** or **Bottom** for temporary basal, scheduled basal, and automatic basal data. Basal injection markers stay with the other treatment markers.

## Screen Lock

Select **Screen Lock** to configure the Clock Mode clock and screen dimming. See [Screen Lock](screenLock.md).

See [Home](home.md) for chart gestures, landscape view, and the other Home sections.
