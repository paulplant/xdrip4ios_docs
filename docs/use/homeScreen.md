# Home Screen

Open **Settings > General > Home Screen** to configure the main chart and other Home options.

## Main Chart

**Main Chart Hours** selects a 3, 5, 8, 12, or 24-hour range. The same control is available under **Quick Show/Hide > Glucose Chart**. Pinching the chart changes the same saved range.

**Show Original Values** displays the original glucose values when [Glucose Adjustments](glucoseAdjustments.md) are active.

**Show Sensor Noise** adds shaded noise bands when this information is available. The bands show how stable the sensor signal was. They do not show glucose accuracy.

**Show IOB/COB** shows available insulin on board and carbohydrates on board curves. The values can come from a connected AID source or can be estimated from recorded treatments. This option controls the chart curves only. It does not stop the calculations or remove the compact values from Home.

**Render Basal Downwards** places temporary basal, scheduled basal, and automatic basal data at the top of the chart. Disable it to return those basal lines to the bottom of the chart. Basal injection markers are not moved by this setting.

## Mini Chart

**Show Mini Chart** shows or hides the longer history chart below the main chart. The range is selected directly from the mini chart.

## Sensor Lifetime

**Prefer Sensor Countdown** shows the estimated time remaining instead of the elapsed sensor time. This changes the display only. It does not extend or stop the sensor.

## Screen Lock

The remaining options control screen rotation, the Clock Mode clock, and screen dimming. See [Screen Lock](screenLock.md).

See [Home](home.md) for chart gestures, landscape view, and the other Home sections.
