# iPad use

xDrip4iOS adapts its main screens to the available iPad window size. The same tabs, data sources, alerts, treatments, statistics, and settings remain available.

## Navigation

On iPadOS 18 or later, the main tabs can appear across the top or in a sidebar. Select Home, Treatments, Statistics, Devices, or Settings in the same way as on iPhone.

Settings uses a sidebar and detail area. Select a settings category in the sidebar to open it. Devices also uses the wider screen to keep navigation and device information clear.

## Home dashboard

Home uses a dashboard layout in both portrait and landscape. Depending on the window width, the current glucose and compact statistics appear together or one above the other.

The main chart uses the remaining space. Portrait also shows an Ambulatory Glucose Profile below the chart when enough history is available.

In landscape, select the expand button on the main chart to open the expanded Ambulatory Glucose Profile. This view compares a selected day with recent history. It also shows Time in Range, average glucose, and coefficient of variation. Select the comparison period or move between days to review how one day differs from the recent pattern.

Clock Mode places the glucose reading and optional clock above the chart. They are stacked in portrait and placed beside each other in landscape. The Clock Mode chart uses a temporary five-hour range in landscape and three hours in portrait. It hides treatment markers and returns to the saved chart range when Clock Mode ends.

## Treatments, Statistics, and reports

On wider windows, Treatments places its date and filter controls beside the treatment list. Statistics can show related cards and charts beside each other. Report options and the PDF preview open in a larger window.

The calculations, report contents, and available actions do not change because of the layout.

## Smaller iPad windows

When xDrip4iOS is used in a narrow window, it changes to a compact layout. Larger accessibility text can also use the compact layout so that information remains readable.

The iPad interface supports portrait and landscape. The iPhone rotation setting does not limit iPad orientation.

Some functions depend on device hardware or another Apple device. For example, an Apple Watch pairs with an iPhone, and direct Libre setup requires NFC.
