# Snooze

Select the Snooze button in the toolbar at the top of **Home** to silence eligible alarms for a selected duration.

The screen lists each enabled alarm and shows whether it is currently snoozed.

## Snooze one alarm

Enable the switch beside an alarm, choose the required time, and select **Snooze**. The row then shows when that snooze will end.

Disable the switch to cancel the snooze before it expires. Snoozing one alarm does not silence the other enabled alarms.

## Snooze all alarms

Enable **Snooze All Alarms**, choose the required time, and confirm it. The screen shows the remaining time while all eligible alarms are snoozed.

Disable **Snooze All Alarms** to allow the alarms to sound again. If an urgent alarm needs attention, the Snooze screen shows this clearly instead of treating it as a normal inactive alarm.

The Snooze toolbar icon on **Home** changes while alarms are snoozed. Open the screen again at any time to check or cancel the current snooze.

## Snooze from a notification

An Alarm Type can allow snoozing directly from its iOS notification. Its **Default Snooze Time** controls the period used by that action. Configure this under **Settings > Alerts and Notifications > Alarms > Alarm Types**.

## Large Snooze Screen

**Large Snooze Screen** is enabled by default. When an active alarm opens the snooze picker automatically, it uses larger controls that are easier to select quickly. Use **Cancel** or **Snooze** to close it.

Disable this option to use the standard-size picker for active alarms. The normal Snooze screen opened from the Home toolbar always keeps its usual layout.

Change the option under **Settings > Alerts and Notifications > Alarms** or **Quick Show/Hide > Additional Items**.

Snooze does not correct the condition that caused an alarm. It does not restore a missing CGM or follower connection.

!!! warning
    Check the current glucose value and reading time before snoozing an alarm. Continue to use the safety methods recommended for the CGM system.
