# Troubleshooting

The **Troubleshooting** section in Settings contains **Activity Log**.

Activity Log keeps a clear history of important app activity from the previous 24 hours. Use it to check recent connections, readings, follower updates, sensor actions, calibrations, alarms, services, and settings changes.

Open **Settings > Troubleshooting > Activity Log**. You can search the on-screen list, copy the complete report, or share it with the person helping you. See [Activity Log](../troubleshoot/activityLog.md).

If the Activity Log is not enough, see [Troubleshooting](../troubleshoot/index.md) for connection, background operation, follower, and reporting help.

**Issue Report** is a separate developer tool under **Advanced Settings**. Use it only when an xDrip4iOS developer asks for it.
