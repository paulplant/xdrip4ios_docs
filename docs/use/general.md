# General

The **General** section contains the glucose unit and the main display and calculation settings.

## Blood Glucose Units

Select `mg/dL` or `mmol/L` before entering glucose ranges, alarm values, calibrations, or blood glucose treatments.

Changing the unit changes how existing values are displayed. It does not change the glucose values received from the sensor. Review manually entered ranges and alarm values after changing it.

## Home Screen

Open **Settings > General > Home Screen** to configure the main chart, mini chart, sensor lifetime display, screen rotation, and Screen Lock. See [Home Screen settings](homeScreen.md).

## Glucose Ranges

Open **Settings > General > Glucose Ranges** to set the urgent high, high, target, low, and urgent low values. See [Glucose Ranges](glucoseRanges.md).

## Treatments

Open **Settings > General > Treatments** to choose how xDrip4iOS estimates IOB and COB from recorded treatments. See [Treatment settings](treatmentSettings.md).

## Statistics

Open **Settings > General > Statistics** to configure the compact statistics on Home. See [Statistics settings](statisticsSettings.md).
