# Settings

The Settings tab configures the data source, display, alerts, sharing services, app information, and advanced behaviour.

On iPad, Settings uses a sidebar and detail area. Select a settings category in the sidebar to open it without leaving the main list.

The main sections follow the order shown in the app:

- [Data Source](../getting-started/dataSource.md)
- [General](general.md)
- [Alerts and Notifications](alertsAndNotifications.md)
- [Sharing and Services](sharingAndServices.md)
- [Data Management](dataManagement.md)
- [Troubleshooting](troubleshooting.md)
- [About xDrip4iOS](aboutXDrip4iOS.md)
- [Advanced Settings](advancedSettings.md).

## Open Online Help

Select the question-mark button on a supported screen to open the help page for that part of the app. The question-mark button on the main Settings screen opens the Settings overview.

When **Translate Documentation** is enabled and the app language is not English, xDrip4iOS opens the relevant page in the selected app language.

See [Settings reference](../reference/settings.md) for a complete list.
