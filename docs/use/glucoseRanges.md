# Glucose Ranges

Open **Settings > General > Glucose Ranges** and set the five marks in a logical order:

1. urgent high
2. high
3. target
4. low
5. urgent low.

Enter values in the currently selected glucose unit. The ranges control the colours on the main chart. Alert thresholds are configured separately.

The detailed **Statistics** tab and PDF reports use standard clinical ranges. They can therefore show different percentages from Home when Home is configured to use personal glucose ranges.
