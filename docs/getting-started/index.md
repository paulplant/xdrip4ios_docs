# Start here

Use this sequence for a new installation.

1. [Install xDrip4iOS](../install/install.md).
2. Open the app and allow the permissions that match the features you will use.
3. Under **Settings > Glucose Display**, select `mg/dL` or `mmol/L` before entering glucose thresholds.
4. Choose **Master** if this device will connect directly to CGM hardware. Choose **Follower** if it will receive readings from an online source or shared calendar.
5. Configure the data source.
6. Confirm that a current glucose value and timestamp appear on the **Home** tab.
7. Review glucose ranges, alerts, notification behaviour, and any sharing services.

!!! tip
    Complete the basic glucose connection before enabling Nightscout upload, Apple Health, widgets, a Watch app, or other optional services. This makes connection problems easier to identify.

## Before you begin

You need an iPhone running iOS 16.2 or later, or an iPad running iPadOS 16.2 or later. Some features require a newer system version or hardware that is not available on every device. Bluetooth, internet access, another online account, a shared calendar, or NFC may also be required, depending on the selected data source.

Do not pair a CGM device in the iPhone's Bluetooth settings unless its manufacturer specifically requires this. Add supported devices from the **Devices** tab in xDrip4iOS.
