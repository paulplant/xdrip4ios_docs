# How to install

**Please note that no public Testflight exist** *(1)*. Do not send us any e-mails asking for links, codes or invitations.

There are still several ways to get xDrip4iOS on your iPhone:

- Install from a personal Testflight invitation found in the [xDrip4iOS Facebook group](https://www.facebook.com/groups/853994615056838) *(2)*
- Build and install the app yourself from source code.
  - Using a Mac with [Xcode](build.md)
  - Using browser build [GitHub/Fastlane](https://github.com/JohanDegraeve/xdripswift/blob/3f658bc086de099bee8cad8526c24efdc6f722c5/fastlane/testflight.md)
- Install Zukka from the App Store *(see below for more information)*

*(1) the public Testflight link has been full for several years. Apple closed down duplicate links so this option is no longer possible.*

*(2) Do not join the Facebook group and post asking for invitations, codes, links. Check the recent messages and see if any invitations are available and follow the instructions in the post. If there are no invitations available, do not post and ask, just consider the other options*



Anybody who is using xDrip4iOS for looping will always need to build from source.

## Zukka

Zukka is a release of the xDrip4iOS project released on the App Store. While it was not created/released in collaboration with the xDrip4iOS team, we have since had open and constructive discussions with the releaser.

Unlike another app that used our free source code and published it on the App Store despite previously promising not to profit from our work and keep it free for all users, Zukka is backed by ongoing communication and a mutual understanding. We have a clear agreement with the person managing the release that Zukka will always allow users to view their blood glucose levels for free. There will never be a paywall for the core xDrip4iOS features as developed by us.

The releaser has clearly communicated that he reserves the right to introduce optional new features in the future, which could be paid - but as of now, there are no plans to do so. We’ve also agreed that any such changes will be clearly communicated in advance and will not affect or restrict the core xDrip4iOS features.

As long as this agreement remains in place, the xDrip4iOS team fully supports Zukka and recommends it as a reliable option.
We will offer full support to all Zukka users in the same way as xDrip4iOS users.
Please note, however, that as with any App Store release of this type, there is a risk that Zukka could be removed at any time. Because of this, our preferred option remains self-build or the private TestFlight releases managed by our trusted releasers.
