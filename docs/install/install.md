# Install xDrip4iOS

xDrip4iOS is not distributed through the public Apple App Store. Install it from a trusted TestFlight invitation or build and sign it yourself.

## TestFlight invitation

A TestFlight build is signed and managed by the person or team that publishes it. Invitations, available places, build expiry, and update timing are controlled by that publisher.

Continue with [TestFlight](testflight.md) if you already have an invitation.

## Build from source

Building requires a Mac, a compatible Xcode version, an Apple ID, and the ability to configure unique signing identifiers. A free Apple developer account can install a development build for a limited signing period. A paid Apple Developer Program membership provides longer-lived signing and TestFlight capabilities.

Continue with [Build from source](build.md).

## Personal TestFlight

A paid Apple Developer Program member can archive a personally configured build and invite selected testers through App Store Connect. The publisher becomes responsible for signing, updates, and access to that build.

Continue with [Personal TestFlight](personalTestFlight.md).

!!! warning
    Only install xDrip4iOS from a publisher you trust. A custom build can change behaviour, data sharing, and available follower sources.
